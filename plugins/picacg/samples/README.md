# 脱敏签到响应样本

从已存在的真实联调日志中提取，没有为采样再次请求接口。

- `success_2026-10-03.json`：首次联调，服务端签到日期 2026-10-03。
- `success_2026-10-04.json`：用户在本地 2026-10-04 12:42 运行，服务端签到日期 2026-10-04。
- `already_signed.json`：已签到后的显式重复提交，返回 `status=fail`，查询仍为已签到。

两个成功样本均为 HTTP 200、业务 code 200、status ok，签到前后 isPunched 从 false
变为 true，经验增加 10。重复提交样本没有增加经验。
样本不含账号、用户标识、密码、Token 或完整个人资料；时间为 UTC。
日常运行不继续采样或写入响应日志。
